## 🛡️ Featured: SOC Lab with Wazuh

**[soc-wazuh-lab](https://github.com/ikram856/soc-wazuh-lab)** — a fully virtualized SOC: 4 VMs (Wazuh server, Linux & Windows agents, Kali attacker) on an isolated network.

| Scenario | MITRE ATT&CK | Detection |
|---|---|---|
| SSH brute force (Hydra) | T1110 | Wazuh rules 5760 / 5503 |
| Port scan (Nmap SYN + UDP) | T1046 | Custom rules 100100 / 100101 + iptables logging |
| File tampering | T1565, T1070.004 | Syscheck FIM + Auditd (whodata) |
| Rogue user creation | T1136 | FIM on `/etc/passwd`, `/etc/shadow` |
| Automatic IP block | T1110 | Active Response (firewall-drop) |
